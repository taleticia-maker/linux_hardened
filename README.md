Servidor Linux Hardened com Automação

Projeto prático de administração e operação de um servidor Linux, configurado, protegido e automatizado de forma incremental, simulando tarefas comuns em ambientes corporativos.

O objetivo é demonstrar conhecimento prático em Linux, segurança, automação e operação de infraestrutura, documentando as decisões, configurações e testes realizados ao longo do processo.

Objetivos
Administração de usuários, grupos e permissões
Hardening e boas práticas de segurança
Configuração e administração de serviços
Automação de tarefas com systemd
Backup e recuperação de dados
Monitoramento de recursos e serviços
Controle de versão com Git
Documentação de procedimentos e troubleshooting

Estrutura do repositório

├── README.md

├── docs/      # Documentação técnica e procedimentos
